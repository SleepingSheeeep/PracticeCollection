# P_Mesh 关卡生成 —— 需求与设计

> 本文档描述 n×n×n 管道关卡的配置方式与程序化生成方案。核心原则：**配置极简**——关卡结构由 txt 描述，颜色随机，形状整关统一。

## 一、需求概述

- 3D 关卡：整体是 `n×n×n` 立方体，由若干颜色不同的**管道**（圆柱体变体：管道 / 箭头 / 蛇）组成。
- 圆柱体全部程序生成，由若干段 mesh 组成一条管道，若干条管道填满整个关卡。
- 通过立方体坐标确定圆柱横截面（圆心、边长），自定义参数确定圆的顶点数，逐顶点生成 mesh。
- 通过沿路径调整半径来表现 管道 / 箭头 / 蛇。

## 二、关键决策

| 决策点 | 结论 |
|--------|------|
| 生成时机 | **运行时生成**（Play 时由代码构建 mesh） |
| 路径来源 | **txt 文件**（固定格式，见第三节） |
| 拐弯处理 | **圆角 / 倒角过渡**（拐点处圆弧弯管衔接） |
| 颜色 | **10 个固定色，随机抽取**（调色板 SO，可扩展） |
| 形状 | **整关统一**（配置里设一个 shape，每种形状一个参数） |

## 三、关卡数据（txt 格式）

- 第 1 行：`n`（关卡维度）。
- 之后每行：一条管道的坐标序列（坐标顺序即方向）。
- 坐标：`x,y,z` 用逗号分隔分量；坐标之间用空格或分号分隔。
- 支持 `#` 开头的注释行与空行。

示例（`Assets/P_Mesh/Levels/示例关卡.txt`，3×3×3 三条蛇形管道分层填满）：

```
3
0,0,0 1,0,0 2,0,0 2,1,0 1,1,0 0,1,0 0,2,0 1,2,0 2,2,0
0,0,1 1,0,1 2,0,1 2,1,1 1,1,1 0,1,1 0,2,1 1,2,1 2,2,1
0,0,2 1,0,2 2,0,2 2,1,2 1,1,2 0,1,2 0,2,2 1,2,2 2,2,2
```

## 四、配置字段

### 4.1 `PipeLevelConfig`（ScriptableObject）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| levelFile | TextAsset | — | 关卡 txt |
| palette | ColorPalette | — | 颜色调色板 |
| cellSize | float | 1 | 单元边长（世界单位） |
| radialSegments | int | 16 | 圆截面顶点数（3~64） |
| bendRadius | float | 0.35 | 拐角圆角半径（≤ cellSize/2，超出自动收紧） |
| straightStep | float | 0.25 | 直线段采样步长 |
| centerLevel | bool | true | 关卡中心对齐世界原点 |
| origin | Vector3 | (0,0,0) | centerLevel=false 时网格左下角世界坐标 |
| shape | PipeShape | Pipe | 整关统一形状 |
| pipeRadius | float | 0.4 | 管道半径 |
| arrowRadius | float | 0.5 | 箭头头部半径（尾部固定为其 30%） |
| snakeRadius | float | 0.4 | 蛇身体半径 |

### 4.2 `ColorPalette`（ScriptableObject）

- `colors`：`List<Color>`，默认 10 个固定色（红/橙/黄/绿/青/蓝/紫/粉/白/灰），可在 Inspector 增删扩展。
- 生成时每条管道从中 `RandomColor()`。

## 五、形状与半径（整关统一，每种一个参数）

半径函数 `r(t)`，`t ∈ [0,1]` 为沿路径归一化弧长：

| 形状 | 半径规则 | 参数 |
|------|---------|------|
| Pipe | `r = pipeRadius`（均匀） | pipeRadius |
| Arrow | `r = lerp(0.3·arrowRadius, arrowRadius, t)` | arrowRadius |
| Snake | `r = snakeRadius + 0.25·snakeRadius·sin(2π·3·t)`，末端 30% 渐变到 `1.4·snakeRadius` | snakeRadius |

（波动幅度、频率、蛇头等比例当前为固定派生值，如需微调可在 `RadiusAt` 中改。）

## 六、生成算法

1. **解析**：`PipeLevelParser.Parse(txt)` → `PipeLevelData { n, paths }`。
2. **坐标转换**：`GridToWorld(coord) = origin + (coord + 0.5)·cellSize`（居中时 `origin = -(n·cellSize)/2`）。
3. **路径采样**：展开成「直线段 + 拐角圆弧段」密集采样点；直线段按 `straightStep` 等距采样，拐角前后各截短 `bendRadius` 后用一段圆弧弯管衔接。
4. **半径**：按第五节 `RadiusAt(t)` 计算每点截面半径。
5. **截面朝向（RMF）**：旋转最小化 frame 沿路径传播截面法向/副法向，避免扭转。
6. **mesh**：每采样点一圈 `radialSegments` 个顶点，相邻圈连成侧面，首尾加端盖。
7. **输出**：每条管道一个子物体（MeshFilter + MeshRenderer + 可选 MeshCollider），颜色随机并写入材质。

### 6.1 拐角圆角几何

拐点 `O`，进入方向 `a`、离开方向 `b`（轴对齐 90°），圆角半径 `r`：

- 圆心 `C = O + normalize(b - a) · (r / sin(θ/2))`，`θ = acos(dot(a,b))`；
- 进入切点 `A = O - r·a`，离开切点 `B = O + r·b`；
- 圆弧绕轴 `axis = normalize(cross(a,b))` 从 `A` 转到 `B`。

## 七、约束与边界

- `bendRadius` 上限 `cellSize/2`，超出自动收紧到 `0.49·cellSize`。
- 每条路径至少 2 个坐标；相邻坐标沿单轴差 1 格；不要原地折返。
- 全部路径需覆盖所有单元且不重复；越界/重复报错，未填满告警。

## 八、使用步骤

1. 在 `Assets/P_Mesh` 下：`Create → P_Mesh → Color Palette`（默认已有 10 色）、`Create → P_Mesh → Pipe Level Config`。
2. 准备关卡 txt（或用 `Levels/示例关卡.txt`）。
3. 在 `PipeLevelConfig` 里：拖入 `levelFile` 与 `palette`，设 `shape`、`cellSize`、`bendRadius` 等。
4. 场景中新建空物体，挂 `PipeLevelGenerator`，把 config 拖到 `Config`。
5. 进入 Play 自动生成；运行时可在组件右键 `Generate (Play Mode)` 重新生成。

## 九、文件结构

```
Assets/P_Mesh/
  需求.md                     # 本文档
  Main Scene.unity            # 场景（挂 PipeLevelGenerator）
  Levels/示例关卡.txt          # 示例关卡数据
  Scripts/
    PipeLevelConfig.cs        # PipeShape / PipePath / ColorPalette / PipeLevelConfig
    PipeLevelParser.cs        # PipeLevelData / txt 解析
    PipeMeshBuilder.cs        # 单条管道 → mesh（采样 / 圆角 / 扫掠 / 顶点）
    PipeLevelGenerator.cs     # MonoBehaviour 入口：解析、生成、校验
```
